# eval/cases

`labels.csv`의 `case_id`와 같은 이름으로 공고 원문을 넣는다. 세 가지 형태 중 아무거나:

- 텍스트: `ablelab_aiml.txt`
- 캡처 한 장: `ablelab_aiml.png` (또는 `.jpg`)
- 캡처 여러 장: `ablelab_aiml/` 폴더 안에 `1.png`, `2.png` … (파일명 순으로 읽는다. `.txt`를 같이 넣어도 된다)

공고 원문은 개인 평가 데이터라 저장소에 올리지 않는다(`.gitignore`). 이 README만 커밋된다.

작성 요령:

- 회사명·공고 제목·주요업무·자격요건·우대사항·근무조건이 모두 보이게 넣는다.
- 세로로 긴 캡처 한 장보다 화면 단위로 2~4장 나눠 찍는 쪽이 인식이 잘 된다.
- 지원 양식에만 있는 조건(예: 경력 선택지가 "3년 이상"뿐)은 폴더에 `.txt`로 한 줄 적어 같이 넣는다.
- 파일이 없는 case는 `run_eval.py`가 건너뛰고 "원문 없음"으로 표시한다.
- 새로 판단한 공고가 생기면 원문을 추가하고 `labels.csv`에 한 줄 추가한다. (평가 세트는 쓰면서 계속 늘린다.)
