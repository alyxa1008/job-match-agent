## 커리어 요약

LLM 기반 기능을 서비스에 붙이고 운영해 온 2년 차 개발자입니다. 사내 문서 검색 챗봇을 RAG 구조로 구축했고, FastAPI 백엔드와 배포 파이프라인을 함께 다뤘습니다.

## 경력기술서

### (주)예시테크    2024.03.01 ~ 2026.02.28 (2년)

- AI 서비스팀 / 백엔드·LLM 개발

**사내 문서 검색 챗봇 (RAG)**
- 사내 위키와 PDF 매뉴얼 약 2,000건을 인덱싱하는 수집·청킹 파이프라인 구현
- 키워드 검색과 벡터 검색을 결합한 하이브리드 검색을 도입하고 리랭킹 단계를 추가해 무관한 문서가 검색되는 문제를 개선
- 답변에 근거 문서 출처를 함께 표시해 사용자가 원문을 확인할 수 있도록 구현
- 임베딩 캐싱으로 평균 응답 시간을 12초에서 4초로 단축

**백엔드·운영**
- Python·FastAPI 기반 API 설계 및 개발, PostgreSQL 데이터 모델링
- Docker와 GitHub Actions로 자동 배포 파이프라인 구성

### (주)샘플랩스    2023.07.01 ~ 2023.08.31 (2개월)
